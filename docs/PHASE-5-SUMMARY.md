## 二、关于 skill 项目的其它建议

按"投入产出比"排序，供后续迭代参考：

1. **模板沉淀"实景组件库"** —— 最高优先。
   本次每个实景都是手写 SVG/CSS。建议在 `templates/presentation/src/components/scenes/`
   预置 `RunnerTrack` / `LiveEditor` / `BlockStack` / `TypeOut` 等**受控组件**
   （接收 `step` 与少量 props），让 agent 直接拼装而非每次从零手画。
   这能把"模拟实景"原则真正落地成"拼积木"，显著降低回归风险。

2. **lint 升级为"实景类型检测"**。
   当前 lint 只判"是否有视觉演示/互动"。建议细分：统计每章命中了
   § 模拟实景 的哪几类，告警"全章都是大字卡片 / emoji 图标"。
   把模式库枚举写成规则，可机检"薄画面"。

3. **EXAMPLES 锚点太少，易照抄套路**。
   目前只有 `example-anime`。建议新增 1~2 个"实景主导" anchor
   （一个用 RunnerTrack 讲算法、一个用 LiveEditor 讲调试），
   避免 agent 照抄 anime 套路导致动画风格固化（文档已警示过此风险）。

4. **"动静结合" reviewer 清单固化**。
   把本阶段手工验证的 3 条（隐藏态占位 / 无 `display:none` / 动画挂 `.cf-reveal.in`）
   做成独立 reviewer 子代理的专用清单，纳入 § 完工自检 流程。

5. **TTS 更稳**。
   edge-tts 偶发网络失败（本阶段 22 段里 3 段失败需重试）。
   建议 `synthesize-audio.sh` 内置"失败段自动重试 / 断点续传"，而非整轮重跑；
   并把零密钥 provider 设为默认推荐。

6. **自动播放与字幕降级的正式契约**。
   用户最初反馈的两点（启动静止 / 字幕加载失败）已用"首屏手势 gate + 字数估时降级"修掉。
   建议在 `README` / `RECORDING.md` 明确浏览器自动播放策略，并把"音频/字幕缺失降级"写成正式契约，
   防止未来又被当成 bug 报回来。

7. **主题 token 强制"无色值字面量"**。
   硬编码 hex 是反复出现的问题。建议在 `DESIGN-SYSTEM.md` 写明禁用清单，
   并在 lint 用正则扫描 `#.{3,6}|rgba?\(` 直接拦截（中性黑阴影除外）。

8. **Phase 编号收口**。
   `CODEBUDDY.md` 定义的是 4 phases，但业务侧用"Phase 5"指代收尾总结。
   建议把"Phase 5 = 交付总结 + 项目建议"显式写进工作流，消除编号歧义。

9. **脚手架主题预览**。
   `scaffold.sh` 之后给一张"主题 → 禁用色 / 字体 / 性格签名"对照表，
   减少 agent 踩主题坑。
