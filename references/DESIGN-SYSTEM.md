# Design System Constraints

写章节代码时的字体、色彩、间距底线约束。每一条都有"为什么"和"什么情况可以例外"——不是空洞禁令。

---

## 字体栈（强制）

课件中英混排是常态，必须显式指定中英文各自的回退字体栈：

| 场景 | 字体 | 说明 |
|:--|:--|:--|
| 中文标题 | `"Noto Sans SC", "Microsoft YaHei", "PingFang SC", var(--font-display-cn)` | 思源黑体优先 |
| 英文标题 | `"Inter", "Manrope", var(--font-display-en)` | 几何无衬线 |
| 中文正文 | `"Noto Serif SC", "Source Han Serif SC", var(--font-body)` | 衬线阅读更舒适 |
| 英文等宽 | `"JetBrains Mono", "Fira Code", var(--font-mono)` | 等宽展示代码/数据 |

> **为什么**：全场不设字体 = 浏览器 fallback 到系统默认（Windows 中易宋体 / macOS 苹方），没有设计感。AI 默认全场 Inter/Roboto 是"看起来像 demo 页"的信号。

> **例外**：课程主题 tokens.css 已预设定制字体（如 chalk-garden），此时尊重主题字体优先。

## 色彩（强制）

### 不用纯黑纯白

| 禁用 | 替换 |
|:--|:--|
| `#000000` 纯黑 | `#0A0A0A`、`#111`、或主题的 `var(--text)` |
| `#FFFFFF` 纯白 | `#FAFAFA`、`#F5F5F5`、或主题的 `var(--surface)` |

> **为什么**：纯黑纯白是出厂色，缺少温度感。近黑+近白保留对比度但视觉更柔和。

### 走 token，不凭空发明颜色

- 背景 → `var(--surface)` / `var(--surface-2)` / `var(--shell)`
- 文字 → `var(--text)` / `var(--text-2)` / `var(--text-mute)`
- 强调 → `var(--accent)` / `var(--accent-tech)` / `var(--accent-good)` / `var(--accent-warn)`
- 分隔 → `var(--rule)`

> **为什么**：凭空发明的 hex 色 = 换主题就破。token = 一套颜色适配所有主题。

> **例外**：CSS 渐变模拟物理环境、动态 inline style 渲染数据驱动颜色——这些是**内容驱动的视觉演示**，不是无意义装饰。

---

## 间距（推荐 · 非强制）

**强制项**：底部留空 60-80px（字幕空间），顶部留空 50-70px。详见 SKILL.md 硬性约束 #8。

**推荐**：优先使用 8px 的倍数间距，保持节奏感：

```
padding / gap = 8 / 16 / 24 / 32 / 48 / 64 / 96
```

> 卡片/段落间距等具体数值由章节内容自由决定，不受额外约束。

## 反 AI Slop 速查

每种"不要"都有"为什么"和"什么情况例外"：

| 元素 | 为什么是 slop | 例外 |
|:--|:--|:--|
| 紫粉对角渐变背景 | AI 语料"科技感"万能公式 | 品牌/课程主题本身用（如某些暗色主题） |
| 全场 Inter/Roboto 单一字体 | 无设计感的出厂字体，看起来像未完成的 demo | 品牌 spec 明确要求 |
| 纯黑 #000 + 纯白 #FFF | 缺少温度感 | 极致黑白主题（极少数） |
| 圆角卡片 + 左彩色 border accent | 2020-2024 烂大街 UI 模式 | 品牌用的 card 组件就是这风格 |
| 每张卡片都配无意义 icon + tag + status dot | 装饰性填充，一眼 AI | 图标承载了**可区分的产品信息**（不是"好看"） |
| 全章 N 步同一种入场动画 | 动画偷懒 | — |
| 每屏右下角挂 mono 角标/序号 | 无内容的标签 | — |
| 编造假数据/假 Logo/假"X 万用户" | 假数据比空着更坏 | — |

### 正向推荐

- ✅ `text-wrap: pretty` + CSS Grid 布局
- ✅ 衬线 display（中英文标题）+ 无衬线 body 混排
- ✅ 一处细节做到 120%（发光数字、渐变背景、分层叠加），其它做到 80%
- ✅ 口播提到真实场景/界面/模板时 → 主动向用户索取素材（"你提到工厂车间监控画面，有对应截图吗？"）
- ✅ 没有素材时 → 用 CSS 视觉模拟（纯色块/代码块/几何形）代替，不编造假截图，不用 emoji 凑结构图
- ✅ 诚实 placeholder > 拙劣的假实现
- ✅ 颜色走 token 或从同课程已有章节 CSS 中继承
